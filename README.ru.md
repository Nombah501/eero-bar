# eero-bar

Неофициальный монитор и панель управления mesh-сетью eero в нативном баре Omarchy. Python 3, только стандартная библиотека: без автоматизации браузера и дополнительных Python-пакетов.

## Возможности

- Состояние сети, время последнего успешного обновления, точки eero, клиенты и профили.
- Поиск и фильтрация клиентов, сведения о точках, клавиатурная навигация и тема хоста.
- Гостевой Wi-Fi, LED точек, пауза клиентов/профилей, тест скорости и перезагрузка с подтверждением.
- Раздельные способы входа: OTP для eero email/телефона и Amazon через браузер.
- Сохранение интервала обновления, плотности строк и отображения клиентов в настройках хоста.

## Требования и установка

Нужны Omarchy с текущим API плагинов service/bar-widget и нативными компонентами `qs.Ui` / `qs.Commons`, его среда Quickshell и Python 3. Документированная базовая версия — **Omarchy 4.0.4**: это не гарантия совместимости со всеми версиями. Для Amazon также нужны рабочий браузер по умолчанию и прямой доступ к локальным loopback-страницам.

**Плагины Omarchy работают без песочницы. Перед включением изучите код и убедитесь, что доверяете ему.** Плагин хранит Session аккаунта и может менять состояние сети.

Установите плагин из GitHub, затем разместите виджет в правой части бара:

```sh
omarchy plugin add https://github.com/Nombah501/eero-bar.git
omarchy plugin enable n501.eero-bar --section right
```

Корень репозитория является корнем плагина.

## Первый запуск

Нажмите значок eero в баре. Для существующего входа eero по email/телефону введите идентификатор, выберите **Send code**, затем введите код и нажмите **Verify**. Адрес Amazon сам по себе не означает поддержку OTP.

Для Amazon выберите **Sign in with Amazon**, завершите ввод пароля/MFA в браузере по умолчанию и вставьте весь возвращённый адрес Amazon в замаскированное поле локальной страницы. Это секрет: не публикуйте его в issue или чате. Вернитесь в панель и нажмите **Save new Session**, только если согласны заменить сохранённую Session. Отмена до одобрения сохраняет прежнюю Session. Подробности — в [руководстве по входу](docs/usage.ru.md#вход).

## Настройки

Откройте страницу Settings в панели; параметры сохраняет хост Omarchy.

| Параметр | По умолчанию | Действие |
|---|---|---|
| `pollSeconds` | `60` | Интервал обновления, 30–3600 секунд |
| `showClientCount` | `false` | Показывать подключённых/всех клиентов у значка |
| `density` | `compact` | `compact` или `comfortable`; тема и шрифт хоста сохраняются |
| `showOfflineClients` | `false` | Изначально включать отключённых клиентов при открытии панели |

## Ограничения и безопасность

Используется **неофициальный API управления мобильного приложения**, а не официальный read-only EU Data Act API. Изменения сервиса могут нарушить работу. Выбирается только первая сеть аккаунта; переключателя сетей нет. Amazon использует текущий US-сценарий по умолчанию: другие регионы, срок жизни Session и ротация токенов не гарантируются.

Переносимые тесты и синтетические проверки нативного интерфейса/браузера не доказывают новый вход или повторный вход человека через Amazon и полную готовность к эксплуатации. Принятый запрос не означает завершённую перезагрузку или изменение настройки: проверяйте последующее состояние. Sign out удаляет только локальную Session, не серверное разрешение.
