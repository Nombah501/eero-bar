# Руководство пользователя

[README](../README.ru.md) · [English](usage.md)

## Вход

### Существующий аккаунт eero по email/телефону (OTP)

1. Откройте панель eero и введите email или телефон существующего входа eero. Телефон указывайте в международном формате `+E.164`.
2. Нажмите **Send code**, введите полученный код и нажмите **Verify**.
3. Успешную проверку одобряет текущий сценарий панели, после чего Session сохраняется локально. Отдельной кнопки Save для OTP нет. Отмена или закрытие popup до одобрения сохраняют предыдущую Session. После выдачи одобрения закрытие popup не отменяет уже согласованный вход.

OTP и Amazon — разные способы. Email аккаунта Amazon не доказывает поддержку OTP в eero. Не запрашивайте коды многократно для неподдерживаемого способа.

### Аккаунт Amazon

1. Выберите **Sign in with Amazon**. В браузере по умолчанию откроется приватная локальная страница возврата со ссылкой на Amazon. Сейчас используется **US-сценарий по умолчанию**.
2. Перейдите по ссылке и завершите пароль/MFA на Amazon. Плагин не читает профиль браузера и не получает пароль Amazon.
3. Скопируйте **весь возвращённый адрес Amazon** текущей попытки и вставьте его в замаскированное поле локальной страницы. Возможная страница **PageNotFound** на Amazon сама по себе не означает неудачный вход: адрес возврата ещё может содержать код авторизации. Никому не передавайте этот адрес.
4. Дождитесь проверки. Вставка адреса — передача секрета, **не согласие на сохранение**. Когда панель сообщит, что новый вход проверен, нажмите **Save new Session**, чтобы заменить предыдущую Session, либо **Cancel Amazon sign-in**, чтобы сохранить её.
5. После успешного сохранения панель обновит данные аккаунта. Страница браузера или промежуточная фаза сами по себе не доказывают сохранение Session.

Используйте локальную страницу и вкладку Amazon только **текущей попытки**. Старые вкладки и адреса не подходят. Отмените неудачную попытку и начните новую, не смешивая их данные.

Локальный приёмник слушает `127.0.0.1` на временном порту, проверяет точный локальный origin и ожидаемый формат возврата Amazon; сырой callback не передаётся панели. Получение адреса ограничено 10 минутами. Для своевременного возврата есть отдельное ограниченное окно обмена и согласия; после готовности проверки на Save даётся 30 секунд. Если время истекло, начните заново. Закрытие вкладки браузера плагин не видит: используйте **Cancel**, закройте popup плагина или дождитесь тайм-аута. Сам браузер не завершается.

При повторном входе старая Session остаётся неизменной до одобрения новой. Отмена, неверный возврат или тайм-аут до одобрения сохраняют её; это не продлевает уже истёкшую Session. Не выходите из аккаунта только ради попытки другого входа.

### Приватность браузера и соединение

Адрес возврата содержит секрет авторизации. История/синхронизация браузера, менеджеры буфера обмена, расширения и другие процессы вашего пользователя могут сохранить его или получить к нему доступ. Helper не читает и не очищает их, не меняет настройки браузера. Не демонстрируйте экран во время передачи адреса; при необходимости очистите буфер/историю средствами своего браузера.

Loopback должен идти напрямую, в обход прокси браузера. VPN/прокси, расширение или настройка приватности могут блокировать локальную страницу или отправку формы с того же origin. Не отключайте защиту глобально: сначала проверьте локальную маршрутизацию и актуальность попытки. Ошибка запуска браузера означает проблему транспорта возврата, а не отказ пароля. Новый реальный вход/повторный вход и видимость адреса возврата в реальных условиях независимо не доказаны; синтетическая проверка локального возврата подтверждает более узкий сценарий.

## Просмотр и управление сетью

Выбирается первая Network аккаунта. Просматривайте Overview, Nodes и Clients; управление Profiles находится в Clients, отдельной вкладки нет. Ищите/фильтруйте клиентов и проверяйте сведения о точке до действия. Неизвестное значение не означает автоматически offline. Reboot и Sign out требуют подтверждения; перезагрузка может прервать связь. Guest, LED и pause меняют реальное состояние сети. Запрос теста скорости не означает немедленно полученное новое измерение.

**Request accepted** — подтверждение принятого запроса, а не результата. **Confirmed by readback** означает, что последующий снимок показал запрошенное булево состояние. **Readback unconfirmed; refresh to check** означает, что подтверждения нет: нельзя предполагать ни успех, ни неудачу. Подтверждение запроса перезагрузки не доказывает восстановление связи. Обновите и проверьте состояние перед повторным действием.

## Настройки

Параметры принадлежат конфигурации bar-widget хоста, а не Session аккаунта.

| Ключ | По умолчанию | Поведение |
|---|---|---|
| `pollSeconds` | `60` | Опрос каждые 30–3600 секунд |
| `showClientCount` | `false` | Подключённые/все в баре; общее число не равно числу подключённых |
| `density` | `compact` | `compact` или `comfortable`, тема и шрифт хоста |
| `showOfflineClients` | `false` | Начальный охват Clients при открытии; не сбрасывает активный поиск/фильтр |

Если хост сообщает, что изменение не сохранено, проверьте настройки eero bar-widget и повторите. При ограничении частоты не нажимайте обновление слишком часто.

## Диагностика

| Симптом | Что проверить |
|---|---|
| Неизвестный статус или отсутствующие сведения | API может пропускать поля или возвращать незнакомые значения. Обновите; unknown не равен offline. |
| Старые данные видны вместе с ошибкой | Это последний успешный снимок, а не доказательство текущего состояния. Проверьте время последнего успеха и соединение. |
| Требуется вход | Session отсутствует или истекла; выберите подходящий способ входа. |
| Код отклонён | Проверьте текущий код и идентификатор; email Amazon не гарантирует OTP. |
| Возврат Amazon отклонён или истёк | Используйте полный адрес текущей попытки на её локальной странице; отмените устаревшую попытку и начните новую. Адрес не публикуйте. |
| Network changed; refresh and try again | Обновите выбранную Network, проверьте цель и осознанно повторите. Действия автоматически не повторяются в другой сети. |
| Request failed / нет readback | Проверьте безопасный текст ошибки и обновите. Принятие запроса и подтверждённое состояние различаются. |
| Rate-limited / network / API error | Подождите; проверьте соединение. Неофициальный API мог измениться. |
| Ошибка панели/import/хоста | Проверьте текущий API плагинов и нативные QML-компоненты хоста. Переносимые тесты не доказывают совместимость хоста. |

В публичный отчёт включайте версии плагина/хоста, обезличенные шаги, безопасный текст ошибки и указание, был сценарий синтетическим или реальным. Не прикладывайте сырой stdout Helper, Session, ответы аккаунта или callback браузера. Уберите имена, идентификаторы, IP/MAC и сведения о сети со снимков экрана. См. [Безопасность](../SECURITY.md).

## Обновление, повторный вход и удаление

Перед обновлением изучите изменения: плагин работает без песочницы.

```sh
omarchy plugin update n501.eero-bar
```

Используйте повторный вход в панели, чтобы заменить Session без предварительного удаления рабочей. **Sign out** удаляет только локальную Session и не гарантирует серверный отзыв. Файл находится в `$XDG_STATE_HOME/n501.eero-bar/session.json`, обычно `~/.local/state/n501.eero-bar/session.json`, с ограниченными правами. Не публикуйте его и не копируйте в публичный репозиторий.

Остановить плагин:

```sh
omarchy plugin disable n501.eero-bar
```

Удалить его клон:

```sh
omarchy plugin remove n501.eero-bar
```

Удаление **не удаляет** Session вне клона. Если нужно удалить локальные учётные данные, выполните Sign out, пока плагин включён, затем отключите/удалите его. Удаление плагина не означает отзыв доступа на сервере.
